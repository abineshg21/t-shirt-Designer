DEFAULT T-SHIRT IMAGES (loaded automatically when the app opens)
Included: round-front.png, round-back.png (Round Neck).
Add more by naming files {type}-{side}.png: polo-front.png, polo-back.png, vneck-front.png, vneck-back.png, hoodie-front.png, hoodie-back.png
Supported: PNG with transparent background, opaque-white PNG with a semi-transparent shading shirt (like the included ones), JPG/WEBP on a plain background.
Types without a file use the built-in vector mockup.
